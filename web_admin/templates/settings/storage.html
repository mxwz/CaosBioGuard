对象存储配置（Cloudflare R2）

第一次使用？跟着这 4 步走
1开通 R2
登录 Cloudflare，进入 R2 控制台开通服务（有免费额度，需绑定支付方式但不扣费）。
2创建 Bucket
在 R2 控制台点「Create bucket」，起个名字（例如 face-images）。
3获取密钥
Overview → Account Details → API Tokens → Manage → Create API Token，权限选 Object Read & Write，复制 Access Key ID 与 Secret Access Key（只显示一次）。
4找 Account ID
在 R2 页面右侧 Account Details 找到 Account ID，拼成下方的 Endpoint。
打开 R2 控制台（创建 Bucket / 获取密钥） 官方教程：如何获取密钥 官方教程：如何找 Account ID
R2 连接信息
把「你的AccountID」替换成第 4 步找到的 Account ID。
密钥只会显示一次，请妥善保管。
Cloudflare R2 固定填 auto，无需修改。
提示
  • 保存后需重启云端服务才生效。
  • Secret Access Key 只显示一次，丢失需重新创建 Token。
  • 权限建议选 Object Read & Write，并可只授权给该 Bucket。
  • 免费额度：10GB 存储 + 每月 1000 万次读请求，出站流量免费。
